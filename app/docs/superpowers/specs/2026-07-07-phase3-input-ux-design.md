# 3단계 — 점수 입력 UX 보강 설계

**작성일:** 2026-07-07
**범위:** `src/pages/Input.tsx` 프론트 UX (DB 변경 없음) + `addScore` 반환값

## 변경
- **입력 목록 순서 고정** — 점수 내림차순이 아니라 팀 이름순(`localeCompare ko, numeric`)으로 고정. 점수 변동으로 행이 재정렬돼 다음 탭이 다른 팀에 들어가던 오탭 버그 해결.
- **중복 탭 방지** — 팀별 `busy` 상태. 요청 진행 중 해당 팀 +/− 버튼 `disabled`(불투명도 저하). 같은 팀 재탭 무시.
- **성공/실패 피드백** — 부여 후 상단 토스트: 성공 `"3팀 +10"`(초록), 실패 `"저장 실패 — 네트워크를 확인하고 다시 시도하세요"`(빨강). 3~4초 후 자동 사라짐.
- **네트워크 오류 처리** — `give()`가 try/catch로 실패를 잡아 사용자에게 원인 표시(기존엔 조용히 실패).
- **빠른 되돌리기** — 성공 토스트에 "되돌리기" 버튼. `addScore`가 새 기록 id를 반환하도록 바꿔, 방금 부여를 즉시 `voidEntry`.

## 완료 기준 충족
- 네트워크 실패 시 원인 표시(에러 토스트).
- 빠른 연타에도 중복 최소화(팀별 busy + disabled).
- 부여 결과가 토스트로 명확, 즉시 되돌리기 가능.
