# 게임당 최대 2팀(1:1 대결) — 설계 문서

**작성일:** 2026-07-16
**대상:** 모든 게임이 1:1 대결로 진행되는 캠프 운영
**한 줄 요약:** 게임당 정원을 2팀으로 서버·화면 양쪽에서 강제하고, 맵에서 빈자리를 한눈에 보이게 하며, "게임 종료" 버튼으로 라운드 전환을 매끄럽게 한다.

---

## 1. 배경과 운영 흐름

- 모든 게임은 **1:1 대결** — 게임당 정확히 2팀이 정원.
- 각 게임 부스의 **스태프가 자기 게임에 도착한 팀을 등록**한다.
- 게임이 끝나면 팀들이 다음 게임을 골라 이동하고, **차 있으면 맵을 보고 빈 게임으로** 간다.

따라서: ① 3팀 등록은 실수이므로 막아야 하고, ② 맵에서 빈 게임이 바로 보여야 하며, ③ 게임이 끝나면 그 게임을 빨리 비워야 다음 팀이 등록된다.

### 확정된 결정 (브레인스토밍)

| 항목 | 결정 |
|------|------|
| 정원 | 게임당 **2팀** (활성 팀 기준; 비활성 팀은 자리 차지 안 함) |
| 강제 위치 | **서버(RPC) + 화면** 이중 — 동시 등록 경합에도 3팀 불가 |
| 꽉 찬 게임 표시(시트) | **비활성 + "가득 참"** 배지 (그 게임에 이미 있는 팀은 예외) |
| 빈자리 가시성(맵) | 배지를 `n/2팀` 으로, 꽉 찬 게임은 흐린 배지로 구분 |
| 라운드 전환 | 게임 카드의 **"종료" 버튼**(스태프·관리자) → 그 게임의 두 팀을 대기로 일괄 이동 |

## 2. 데이터 모델·서버

새 컬럼 없음. 마이그레이션 005에서 함수 두 개만 다룬다.

### 마이그레이션 `supabase/migrations/005_game_capacity.sql`

1. **`set_team_game` 교체** — 정원 검사 추가:
   - `p_game`이 null이 아니면 `games` 행을 `for update`로 잠가 동시 이동을 직렬화.
   - 그 게임의 활성 팀 수(자기 자신 제외)가 2 이상이면 `raise exception '이미 2팀이 참여 중이에요.'`
   - 같은 게임 재지정은 통과(변화 없음), 대기(null) 이동은 검사 없음.
2. **`clear_game(p_game)` 신규** — 그 게임에 있는 모든 팀의 `current_game_id`를 null로. `set_team_game`과 같은 SECURITY DEFINER + admin/staff 역할 검사 패턴. 원자적이라 "한 팀만 빠지는" 부분 실패가 없다.

### 상수

`src/lib/constants.ts`에 `MAX_TEAMS_PER_GAME = 2` (서버 함수의 2와 짝 — 주석으로 상호 참조).

## 3. API — `src/lib/api.ts`

- `setTeamGame`: 에러 코드가 `P0001`(우리 함수의 `raise exception`)이면 서버의 한글 메시지를 그대로 던진다. 그 외는 기존 일반 메시지.
- `clearGame(gameId)`: `clear_game` RPC 호출. 실패 시 "게임을 비우지 못했습니다."
- `src/lib/database.types.ts` `Functions`에 `clear_game: { Args: { p_game: string }; Returns: undefined }` 추가.

---

## 4. 화면 — `src/pages/Map.tsx`

- **정원 배지**: 게임 카드 배지를 `1팀` → `1/2팀`. 꽉 찬 게임(2/2)은 흐린 배지로, 빈 게임의 흰 배지가 눈에 띄게. 대기 카드는 기존 `n팀` 유지.
- **게임 종료 버튼**: 카드 헤더에 팀이 있는 게임 + 편집 권한(admin/staff)일 때만 노출. 탭 → `ConfirmModal`("게임을 끝내고 팀들을 대기로 보낼까요?") → `clearGame` → 토스트.
- **팀 이동 시트**: 꽉 찬 게임 항목은 `disabled` + 흐림 + "가득 참" 배지. 단 그 게임에 이미 있는 팀에게는 정상(체크 표시).
- **`move()` 클라이언트 가드**: 꽉 찬 게임으로의 이동은 호출 전에 토스트로 차단(서버 검사는 경합 시 최후 방어선).
